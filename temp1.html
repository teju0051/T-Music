Java Programs practice

A) Write a program in Java to demonstrate Boolean value

class DemoBoolean {
    public static void main(String args[]) {
        boolean a = true;
        boolean b = false;

        System.out.println(a);
        System.out.println(b);
    }
}

B) Write a program in Java to print a string 10 times using loop

class LoopPrint {
    public static void main(String args[]) {
        int i;
        for(i = 0; i < 10; i++) {
            System.out.println("Java");
        }
    }
}

C) Write a program in Java to evaluate a + b * c % d

class Calculate {
    public static void main(String args[]) {
        int a = 5;
        int b = 4;
        int c = 3;
        int d = 2;

        int ans = a + b * c % d;
        System.out.println(ans);
    }
}
